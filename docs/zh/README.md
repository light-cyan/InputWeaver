# InputWeaver 使用文档

InputWeaver 用来重映射键盘和鼠标输入，并用 Weave 编写按键宏、条件动作和鼠标手势。可以在界面中创建、编辑和运行程序，也可以使用命令行编译和运行 `.weave` 文件。

## 从这里开始

第一次使用，请从[第一个输入映射](getting-started.md)开始：创建程序，让记事本中的 A 键变成 B 键，再学习运行和停止。已经有 `.weave` 文件，可以直接查看[界面操作](tui.md)中的导入步骤。

## 文件与程序名称

| 名称 | 用途 |
| --- | --- |
| `.weave` | 可以编辑的 Weave 源文件 |
| `.weavec` | 编译完成后供执行器运行的文件 |
| `InputWeaverHost.exe` | 界面和托盘入口 |
| `InputWeaverTUI.exe` | 界面组件，由 `InputWeaverHost.exe` 自动启动 |
| `InputWeaverCompiler.exe` | 校验、编译源码和生成编译内容的文本视图 |
| `InputWeaver.exe` | 运行 `.weavec` 文件的执行器 |

在界面中按空格运行时，InputWeaver 会根据源码是否修改过决定是否先编译；命令行的对应步骤见[命令行](command-line.md)。
